# Phase 7G - Group B 1.9 Lambda 2-Degree Boundary Repair

Phase 7G fine-tunes the Phase 7F broad-coverage model with boundary-aware sampling that emphasizes the coherent 2-degree regime, then evaluates on the reused 40-cell grid for direct comparison against Phases 7E and 7F.

Experimental conditions:
- Array: Group B 12-channel 2D hardware geometry
- Physical spacing: 1.9 lambda
- Model family: SS(2/3 x 3) -> LRMC -> width-controlled anti-rectifier spatial fusion -> SubspaceNet backbone 3x3 -> ESPRIT
- Initialization: fine-tune from the best Phase 7F checkpoint
- Training schedule: 8 sequential repair stages
- Per-stage mixed dataset size: 45,000 total samples
- Per-stage split: 40,500 training / 4,500 test samples
- Coherence weighting: 60% coherent, 40% non-coherent
- Boundary emphasis: coherent 2-degree cells are the dominant repair target
- Evaluation set: same reused 40-cell grid as Phases 7E and 7F
- Primary metric: horizontal-angle RMSE in degrees
- Comparison focus: coherent 2-degree repair vs Phase 7F with anchor retention

Reference anchor RMSE: `0.3592 deg`
